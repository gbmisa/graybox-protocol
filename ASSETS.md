# Graybox Protocol — Asset Licenses

## Procedurally Generated Assets (CC0 / Proprietary)

All in-game geometry, characters, and props are procedurally generated in GDScript using Godot's built-in mesh primitives (BoxMesh, CapsuleShape3D, etc.).

- **Guard models:** Dark-red boxes with simple arm geometry
- **Target model:** Dark suit with tan head, simple arms  
- **Level architecture:** Gray-box compound walls, crates, rooftop
- **Props:** Varied-color cover crates, scaffolding, extraction zones
- **Visual effects:** Particle effects (screen shake, hit flashes, audio synthesis)

All source code is original and available in `scripts/`.

## External Dependencies

None. The project uses only:
- Godot 4.7.2 (MIT)
- GDScript (built-in)
- Standard 3D primitives
