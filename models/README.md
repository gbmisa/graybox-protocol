# Graybox Protocol — Model Pack v1

Built 2026-10-01 by Fount in Blender 4.2. Low-poly, flat-shaded, matching the
game's graybox aesthetic. Yours to use freely (no third-party assets).

## Importing into Godot 4

1. Copy the `glb/` files into your project (e.g. `res://models/`).
2. Drag a `.glb` into the scene tree — Godot imports it as a scene. Double-click
   the `.glb` in the FileSystem dock to adjust import settings (make sure
   **Root Type** / node naming suits you).
3. Materials come through as StandardMaterial3D. Emissive bits (visors, rotor
   running lights, gun-pod muzzles) use real emission and will glow.

Conventions:
- Characters face **+Y** in Blender → Godot shows them facing **-Z** (forward).
  Feet at y=0, ~1.7–2.0 m tall. No armatures yet — they're static posed meshes,
  ready to rig when you want animations.
- `fp_arm.glb`: origin sits where the **camera** goes; barrel points along **-Z**.
  Parent the imported scene to your Camera3D as-is — no rotation needed.
- `rotorcraft.glb` contains one Animation (`rotor_0`/`rotor_1` counter-rotation).
  In Godot it shows up as an AnimationPlayer — just play it.

## Secret room (`secret_room.blend`)

A 7×6×3.2 m hidden safehouse: desk with 3 glowing monitors, office chair,
weapon rack with 3 rifles, floor safe, evidence board, crate shelves, and a
**bookcase that's slightly ajar** revealing a dark hidden passage behind it.
Lit with cool ceiling panels + a red emergency lamp. Camera `room_camera` is
already framed — open the file, F12 to re-render.

To get it into Godot: either rebuild it from the layout, or export pieces as
glTF from Blender (File → Export → glTF). It's kept as `.blend` so you can
edit it first.

## Tweaking

Every model has its `.blend` source in `blend/`. Colors are simple Principled
materials named per-part (`civ_01_shirt`, `guard_enforcer_visor`, …) — select
the mesh, go to the Material tab, change Base Color. The whole pack is
generated by `build.py` (`blender -b -P build.py -- <name>`), so variants are
cheap to add — ask Fount.

## Notes / limitations

- Characters are unrigged (no skeleton). Good enough for standing NPCs and
  guards; rig when you need walk/death animations.
- Poly counts are tiny (a few hundred tris per character) — fine for crowds.
- The rotorcraft is stylized on purpose: coaxial twin rotors, no tail rotor,
  "rule of cool" over aerodynamics, per the brief.
